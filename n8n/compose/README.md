# Deploy on CSC Rahti

This is simply. Just run:

```bash
docker compose up -d
```

Then, access the n8n instance at `http://localhost:5678`, minio console at `http://localhost:9001`, and Mattermost at `http://localhost:8065`.

However, there is very little reason to run this locally. Getting the app running in Rahti takes just a few more minutes and enabled e.g. collaboration and public access for workshop participants.
