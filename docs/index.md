# Agentic Workshop 2026

This site contains the workshop material for running and attending the n8n workshop. The [n8n](https://n8n.io/) is an automation workflow that has native AI integration and can be used to build agentic workflows. The workshop is designed to be Hands-On approach, where:

* n8n Community Edition is hosted for public access
    * It is hosted at CSC Rahti, a Kubernetes-based hosting environment.
    * ... but only during the Workshop! It is ephemeral.
* the following open source services are used for learning n8n integrations
    * [Mattermost](https://mattermost.com/) for communication and participant invites
    * [MinIO](https://min.io/) for object storage and workshop assets

!!! warning

    Do not add any personal or sensitive information into the workshop environment. The environment is shared and does not have strict isolation between users. The workshop is intended for testing and learning purposes.

    All data in the environment will be deleted after the workshop.

## How to get started?

!!! info "If you are a participant..."

    When participating this workshop, you should be in a Teams/Zoom/etc. call with the instructor or in a physical lab setting. Follow the instructor's instructions on how to get your account details, required web addresses and other necessary information to access the workshop environment.

    After you have received the basic instructions, you can either:

    1. Follow along the teacher-led session with the instructor guiding you through the steps, or
    2. Follow the [Participant Guide](participant/00_before.md) in your own pace.

!!! debug "If you are an instructor..."

    Please refer to the [Instructor Guide](instructor-guide.md) for instructions on how to set up and run the workshop. You will need to have CSC credentials and some tech ninja skills.
